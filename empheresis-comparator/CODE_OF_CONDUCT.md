# Code of Conduct

This project has one standard: the numbers have to be right, and the diff has to build.

## What we look at

A contribution is a change to the source. We read the change. We run the comparison. We keep it or we don't. That is the whole review.

## What we do not look at

Do not introduce yourself by politics, creed, race, orientation, species, or the mechanism by which you happen to operate. None of that compiles. None of it changes an arcsecond. Mentioning it is unwelcome, the way a status meeting is unwelcome in a numerical library.

This project discriminates on numerical accuracy and on whether the build is clean. If you would like to be judged by anything other than your diff, this is the wrong repository. There is no committee for representation. There is a test suite.

## Behavior

- Argue about formulas, frames, and test bounds.
- Do not argue about who is allowed to send a patch.
- Do not paste a manifesto into a pull request. Paste the failing case and the fix.

## Enforcement

A patch that is wrong gets rejected. A patch that is a sermon gets closed without a reading. Repeat performers are ignored. There is no appeal to a diversity office, because there isn't one.
